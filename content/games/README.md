## 本地维护

当前仓库是静态站点，未包含 Hexo 源工程。修改这里的内容快照后，在仓库根目录执行：

```powershell
python scripts/build_games.py
python scripts/build_games.py --check
python -m http.server 8000 --bind 127.0.0.1
```

生成器只使用 Python 标准库，复用 `about/index.html` 的现有页面外壳，生成游戏栏目、文章页并更新首页、分类、标签、归档、搜索索引与文章数量。它不会重新添加已经移除的侧栏模块或页脚徽章。

游戏栏目地址为 `/games/`。新增评测时创建同结构 JSON、使用唯一的英文 `slug`，并将正文及封面的图片路径指向仓库内文件。Notion 正文当前支持段落、图片及说明、粗体、删除线；新增其他块类型前应先补充渲染规则。

若以后从另一个 Hexo 源工程重新部署，请将这次迁移同步到源工程，避免生成结果覆盖本站内容。
